# Swotty

A study planner for students (SwiftUI, iPhone and iPad). Track exams,
assignments and quizzes, set reminders, sync due dates to the Calendar app,
run a Focus timer, and review results with charts.

All data stays on the device (UserDefaults). No accounts, no tracking.

## Getting started (on a Mac)

```bash
brew install xcodegen
xcodegen generate      # creates Swotty.xcodeproj from project.yml
open Swotty.xcodeproj
```

The `.xcodeproj` is generated, not committed. Edit `project.yml` to change
build settings, then re-run `xcodegen generate`.

Before your first device or App Store build, in `project.yml`:

1. Set `PRODUCT_BUNDLE_IDENTIFIER` to the ID registered in
   *Certificates, Identifiers & Profiles* (currently a placeholder).
2. Uncomment `DEVELOPMENT_TEAM` and add your Team ID.
3. A placeholder app icon is included. Replace
   `Swotty/Resources/Assets.xcassets/AppIcon.appiconset/icon-1024.png`
   with your own 1024×1024 PNG (no transparency) when ready.

No Mac? See [docs/TESTFLIGHT.md](docs/TESTFLIGHT.md) to build and upload to
TestFlight from GitHub Actions.

## Layout

| Path | What it holds |
| --- | --- |
| `Swotty/SwottyApp.swift` | App entry point, app name/version |
| `Swotty/Models/` | `Subject`, `Assessment` and option types |
| `Swotty/Store/StudyStore.swift` | All data, saved automatically |
| `Swotty/Services/` | Reminders (notifications) and Calendar sync (EventKit) |
| `Swotty/Views/` | One file per screen, plus shared components |
| `Swotty/Resources/` | Assets, privacy manifest (Info.plist is generated by XcodeGen) |
| `SwottyTests/` | Unit tests |

## Testing

`xcodebuild test -project Swotty.xcodeproj -scheme Swotty -destination 'platform=iOS Simulator,name=iPhone 16'`

CI (`.github/workflows/ios.yml`) runs the same on every push and pull request.

## Releasing

Archive from Xcode (*Product → Archive*), then upload to App Store Connect
via the Organizer. Bump `CURRENT_PROJECT_VERSION` in `project.yml` for every
upload; bump `MARKETING_VERSION` for each public release.
